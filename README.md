# Rocket Blast 🚀
2-player 'space invaders' clone

# Gameplay
- Control the rocket ship (arrow keys) or the penguin (A/D)
- Shoot projectiles with space bar (rocket) or 'S' (penguin)
- Take out the asteroids before they reach you!

# Technical

- Made with Greenfoot
- Features projectile spawning and firing, asteroid sequence generation
